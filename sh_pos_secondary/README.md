About
============
Do you want the secondary unit of measure in the point of sale (POS) product? Yes! So, You are at the right place, We have created a beautiful module to manage a secondary unit of measure in POS product. It will help you to get easily secondary unit value. so you don't need to waste your time to calculate that value. cheers!

Installation
============
1) Copy module files to addon folder.
2) Restart odoo service (sudo service odoo-server restart).
3) Go to your odoo instance and open apps (make sure to activate debug mode).
4) click on update app list.
5) search module name and hit install button.
